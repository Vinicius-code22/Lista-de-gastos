# 💸 Expense Control (Java)

Sistema de controle de gastos desenvolvido em Java com persistência em arquivo CSV.

## 🚀 Funcionalidades

- Adicionar gastos
- Listar gastos
- Ver extrato (soma total)
- Salvamento automático em arquivo

## 🛠️ Tecnologias

- Java
- Programação Orientada a Objetos (POO)
- Manipulação de arquivos (FileReader, FileWriter)

## 📂 Estrutura do Projeto

- `application` → classe principal
- `entities` → entidade Expense
- `services` → regras de negócio

## 💾 Armazenamento

Os dados são salvos em: C:/VnxGastos/dados.csv

## 📸 Demonstração

Exemplo de uso no console:

R$ 50.00 | Mercado | 20/04/2026
R$ 30.00 | Uber | 21/04/2026

Total: R$ 80.00


## ▶️ Como executar

1. Clone o repositório
2. Abra no Eclipse
3. Execute a classe `Main`
